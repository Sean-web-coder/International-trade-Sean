让网页连接你的 Codex

网页将任务发送到你的 Windows 连接器，由本机 Codex 完成研究。电脑需要保持开机，连接器窗口需要保持打开。

  1. 电脑上安装 Python 3.10+、Node.js LTS 和 Codex CLI，并执行 codex login 登录。
  2. 从 GitHub 下载项目，解压后双击 connect-codex.bat。
  3. 在连接器中输入下面的网址和进入网页时使用的连接码。

连接码不会上传到 GitHub。它可访问你的工作台，请勿分享。Codex 登录信息保留在电脑上，模型调用使用该账户额度。

已登录不代表模型可调用；测试成功才表示 AI 已能响应。
