# TradeScout 产品决策记录

记录用户已确认的决策，以及仍需回答的问题。应用规则以最终确认的方案为准。

## 已确认（第一轮）

1. 第一版聚焦 **2–3 个国家的区域批发商、进口商**；国家名单待定。
2. **人工逐条核实关键证据后才计分**。模型搜索结果可以作为待审线索，但不能自动标记为已确认。
3. 与邮箱集成的第一步是**创建草稿**，由用户在邮箱中审核并发送。系统需要同步或记录实际发送事实，不能把草稿当已发送。
4. 客户资料、邮件和跟进记录必须长期保存。Render 免费实例中的 SQLite 不是目标存储，需配置持久化数据库和可恢复备份。

## 第二轮待确定

- 首批 2–3 个国家。
- 产品大类和可证明的差异化价值。
- 用户的工作邮箱提供商，决定合法授权和草稿/发送状态同步方式。
- 托管数据库预算和是否已有可用服务。

## 后续依赖决策

- 目标买家的筛选阈值、来源渠道和同域名去重规则。
- 证据验证标准、批准者、过期复查与更正审计。
- 联系人来源和邮箱校验。
- 发信的语言、模板、时间与法律/退订规则。
- 何时视为已发送、如何发现回复、停止跟进条件、提醒频率。
- 团队人数与权限；是否需要共享客户和任务。
- 旧 SQLite 客户数据迁移、备份频率与恢复演练。
