# 第二阶段：人工证据审核

已在开发分支加入逐项审批，但尚未部署到线上。

- Codex 背调结果作为候选证据保存，六项分数一律从 0 开始。即使 AI 写了 `confirmed=true`，也不直接计分。
- 客户页显示来源链接和证据描述，由用户逐项通过、驳回或留待核实；通过时必须填写实际核对的公开网址。
- 仅已通过的项目按原权重计分，邮件生成只接收已通过的事实。没有可信中国采购证据时保留客户、该项 0 分。
- 再次背调同一公司会清除旧审批并要求重审；旧版数据库中的模型自评分会迁移为 0。JSON 备份包含审批记录，旧版无审批记录的备份恢复后也从 0 分开始。
- 本地自动测试覆盖待审 0 分、驳回、非法来源、通过加分、草稿事实过滤与重背调重审。

上线验收仍依赖第一阶段的数据库与真实 Codex 连接完成，然后由用户打开实际来源核查至少一家公司。
