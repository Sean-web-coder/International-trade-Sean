# 外贸开发信小助手（本机骨架）

这是第一阶段的本机应用：客户列表、CSV 导入、邮箱设置、SMTP/IMAP 连接测试和每 30 秒刷新的概览。**当前没有开发信生成、排期、发送或收信监控功能。**“生成开发信”和“开始发送”按钮已禁用，后端也没有相应接口。

## 启动

1. 在你自己的电脑上安装 Node.js 20 或更高版本。
2. 从仓库下载 ZIP 并解压，打开其中的 `mail-helper` 文件夹。
3. Windows 双击 `Windows-启动.bat`；Mac 双击 `Mac-启动.command`。首次启动会自动运行 `npm install`。
4. 等待终端出现“本机服务已启动”，再打开 `http://localhost:48173`。启动窗口必须保持打开。
5. 停止程序时，在启动窗口按 `Ctrl+C`。

若 Mac 提示脚本没有执行权限，可在该文件夹的终端运行 `chmod +x Mac-启动.command`，再双击。也可以直接在该文件夹运行 `npm install` 和 `npm start`。

服务仅监听 `127.0.0.1`。如果 48173 端口被占用，先退出占用该端口的程序；不要随意结束其他 Node 进程。

## 导入客户

准备 UTF-8 编码的 CSV 文件，第一行必须是：

```csv
公司名,联系人,邮箱,备注
```

每行需要公司名和有效格式的邮箱；联系人、备注可留空。重复的“公司名＋邮箱”会跳过，导入结果会列出无效行号。请只导入你批准的客户。初始的三条“演示客户”是虚构记录，没有邮箱，也不计入客户总数；它们只用于展示页面布局。上一轮的马达加斯加候选没有被当作已批准客户导入。

## Gmail 设置

打开“邮箱设置”，点击“填写 Gmail 常用服务器”。通常是 SMTP `smtp.gmail.com:465`（TLS）和 IMAP `imap.gmail.com:993`（TLS）。填写你的 Gmail 地址、应用专用密码、发件人名称（如 Sean）和签名，点击“保存设置”。

Gmail 应用专用密码通常需要先在 Google 账号中开启两步验证，再到账号安全设置创建；某些组织账号可能不提供此选项。**不要把密码发到聊天里。**保存后页面只显示“已保存”，不会返回明文。连接测试分别调用 SMTP `verify()` 与 IMAP 登录后退出，**不会发送测试邮件**。

数据保存在项目内的 `data/`。应用专用密码在 SQLite 中加密；加密密钥是同目录的 `settings.key`。备份时请将整个 `data/` 一起备份并妥善保管。此目录已加入 `.gitignore`。

## 当前监控口径

- 客户总数：已导入的真实记录，不含演示数据。
- 待发送、已发送：为下一阶段预留的邮件状态表统计，当前应为 0。
- 已回复、已退信：为下一阶段预留的客户状态统计，当前应为 0。
- 页面每 30 秒重新读取后端数据。

## 后续接入

客户表已有 `source` 字段，当前 CSV 导入记为 `csv`。未来 Apollo 可以作为新的导入来源，在同一客户记录结构上补充公司与联系人信息，再接背调、人工审核和发送流程。现在没有 Apollo 调用，也没有发送功能。
